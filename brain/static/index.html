Install Shadow Cursor (one time)
  1. Download for Mac
  2. Open it and drag Shadow Cursor to Applications.
  3. Open Shadow Cursor. If macOS blocks it, go to System Settings › Privacy & Security and click Open Anyway.
  4. Allow Microphone, Accessibility and Screen Recording when macOS asks, then quit Shadow Cursor from the pink icon in the menu bar and open it again.

This page continues by itself once Shadow Cursor is open.
